# 🌦️ Weather App

This is a modern React application that allows users to search for any city and get real-time weather information through a clean and responsive user interface.

## 🚀 Features

* Search for weather by city name
* Fetch real-time weather data from an external API
* Display temperature and weather conditions
* Show additional details such as humidity and wind speed
* Responsive design for desktop and mobile devices
* Clean and user-friendly UI

## 🛠️ Built With

* React.js
* JavaScript (ES6+)
* CSS3
* Weather API
* Vite

## ⚙️ How It Works

The application sends a request to a weather API based on the city entered by the user, retrieves the latest weather information, and dynamically displays the results in a clean and organized layout.
