📌 Simple Movie Search App
This is a simple React application that allows users to search for movies using an external API and display the results in a clean card-based layout.

🚀 Features
Search for movies by name
Fetch real-time data from a movie API
Display results as responsive cards
Show movie details like title, poster, and release year
Simple and user-friendly UI
🛠️ Built With
React.js
JavaScript (ES6+)
CSS
Movie API (like OMDB or TMDB)

⚙️ How It Works

The app sends a request to the movie API based on the user’s input, retrieves matching results, and dynamically renders them as cards on the page
